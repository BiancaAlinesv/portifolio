# Portfolio de Bianca Aline

Portfólio e currículo digital desenvolvido com foco em apresentação profissional.

## Sobre

Este projeto é um website estático de portfólio com design moderno, estilo escuro e interações suaves. O site inclui:

- Hero com CTA claro e botão de download de currículo em PDF
- Seções de Sobre, Projetos, Habilidades e Contato
- Tema claro/escuro com persistência via `localStorage`
- Animações de entrada e efeitos sutis para uma apresentação impactante
- Estrutura responsiva para dispositivos móveis

## Estrutura do projeto

- `index.html` — página principal do portfólio
- `assets/styles.css` — estilos e temas do site
- `assets/script.js` — lógica de interações, tema, menu móvel e animações
- `curriculo.pdf` — currículo mock para download direto

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

## Como usar

1. Clone este repositório:
   ```bash
   git clone <URL-do-repositório>
   ```
2. Abra `index.html` no navegador.

## Personalização

Você pode ajustar o conteúdo e as seções diretamente em `index.html` e adaptar as cores em `assets/styles.css`.

## Observações

Este projeto foi projetado para servir como portfólio pessoal e ferramenta de apresentação profissional. O botão de download do currículo adiciona uma forma direta de compartilhar informações com recrutadores e clientes.
